# Autoresearch Paper

Autoresearch Paper develops a research question into a manuscript and an
evidence package. The `autoresearch` skill coordinates the stages and checks
the evidence required for each handoff.

The workflow compares venues, reads figures and tables in accepted papers,
freezes a plan, verifies citations, runs experiments, and prepares the
manuscript for independent review. Delivery includes a compiled PDF,
editable sources, and evidence that can be checked against the plan.

The user chooses the venue and answers the budget question. The host reads
sources and judges scientific claims. The controller verifies artifacts,
recorded usage, and stage requirements.

The skill runs in Claude Code, Codex, OpenCode, pi, and Muse. The
[installation guide](../guide/getting-started.md) shows the entry points.
The [runtime contract](../foundation/references/runtime-contract.md) describes
the stage handoffs and recovery commands. The
[repository](https://github.com/WdBlink/autoresearch-paper) is maintained by WdBlink.
